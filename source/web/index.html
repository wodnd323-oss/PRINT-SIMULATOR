현재 기준과 사용 범위

기본 기준: 디자이너 전달본 「케이스 7 · 130 × 32 × 130 mm.pdf」를 내장 GRACoL2013_CRPC6로 해석한 색과 기존 파란 7번 케이스 사진의 같은 부위를 다시 추출했습니다. 배포 ZIP의 사진은 이미 sRGB로 변환된 자산이며 이를 그대로 보존했습니다. 조명·노출·화이트밸런스 영향이 포함될 수 있습니다. 인쇄소 내부 ICC 변환 과정을 재현한 모델이 아닙니다.

적용 방식: 기준점에서 전반적인 채도·색조 변화와 밝기 경향을 계산해 모든 유채색에 적용합니다. 기존 기준색 근처에는 사진과의 남은 차이를 추가로 맞춥니다. 중성 회색과 흰색은 색이 치우치지 않도록 유지한다는 가정을 사용합니다.

녹색과 새 색상: 연결된 기준색이 없어도 전체 경향으로 보정합니다. 파랑·금색에서 학습한 경향이 다른 색에도 통한다는 가정이므로 새 색은 미검증 외삽입니다. 다른 종이·코팅·인쇄소·조명에서 통용되는 보정 ICC가 아닙니다. 사진을 통한 맞춤은 측정기 기반의 인쇄 특성화와 다릅니다.

배포 기준의 검증 범위: 같은 사진 학습 평균 ΔE76 1.58. 같은 입력색을 묶어 모두 제외한 검사 평균 5.81, 최대 19.91입니다. 새 색 계열과 새 인쇄물의 정확도는 검증하지 않았습니다. 계산 방법과 재점검 결과 보기

사용 방법

V11.2 변경 내용과 검증

왜 이렇게 계산하는지 · 계산 방법 재점검

  1. START.cmd로 실행합니다. 창이 이미 열려 있으면 그대로 사용합니다.
  2. PDF / 이미지 열기에서 신규 PDF를 선택합니다. 여러 페이지는 왼쪽 페이지 메뉴로 바꿉니다.
  3. 이미지에서 이미지 복사를 하거나 Win+Shift+S로 캡처한 뒤, 기본 화면에서 Ctrl+V를 누르면 비교 이미지로 열립니다. 목표색 역산 창에서 붙여넣으면 목표 이미지로 열립니다. 각 화면의 붙여넣기 버튼도 사용할 수 있습니다. HEX 등 글자 입력칸에서는 일반 텍스트 붙여넣기를 유지하므로 이미지 붙여넣기는 빈 부분을 클릭하고 실행하세요.
  4. 두 예상 화면을 비교합니다. 휠·＋/−로 확대하고 드래그로 이동할 수 있습니다. 실물 기준 사진 관리는 기준색 추가·수정에서 열 수 있습니다.
  5. 새 색 추정 영역 표시에서 자주색으로 보이는 색도 전체 경향으로 계산됩니다. 자주색은 기존 인쇄물에서 직접 확인하지 못한 외삽 영역을 뜻하며, 실제 인쇄색이 아닙니다.
  6. 녹색 등 새 기준을 직접 추가하려면 해당 인쇄 원본 PDF와 실물 사진을 선택한 뒤 기준색 추가·수정에서 대응색을 추가합니다. 같은 색조라도 밝기와 진하기가 다른 여러 부분을 고르면 범위를 늘릴 수 있습니다.
  7. PNG · 다른 이름으로 저장은 오른쪽에 선택한 결과를 저장합니다. 사진 예상·표준 프루프·범위 표시·경고 화면 중 원하는 보기를 먼저 선택하세요. 원본 PDF는 수정되지 않습니다.
  8. 다른 PC에서는 이 폴더와 보정 기준 내보내기로 저장한 JSON을 옮깁니다. 같은 기준으로 계산하더라도 모니터마다 보이는 색은 다를 수 있습니다.

강도 100%는 사진 차이의 반영량입니다. 실제 인쇄 정확도 100%를 뜻하지 않습니다.
