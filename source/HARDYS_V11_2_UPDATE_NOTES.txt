HARDYS 인쇄색 시뮬레이터 V11.2
2026-11-23 목적 적합성 재검토 후 업데이트

무엇이 바뀌었는가

1. 색상 조회의 늦은 응답이 최신 입력의 결과를 덮어쓰지 않도록 수정했습니다.
   입력·계산 기준·보정 기준·강도를 바꾸거나 창을 닫으면 이전 결과를 무효화합니다.

2. 직접 색상 비교창에서 사진 모델과 FOGRA39 표준 프루프를 선택할 수 있습니다.
   역산 결과의 '같은 조건으로 RGB/CMYK 확인' 버튼은 추천값, 모드,
   CMYK 프로파일, 사진 강도, 보정 기준을 유지한 채 다시 계산합니다.
   추천 이후 보정 기준이 바뀌었다면 다시 역산하도록 안내합니다.

3. 그라데이션의 정확한 CSS 각도와 좌표 기준을 화면·TXT에 표시합니다.
   두 점을 지정한 경우 원본 좌표, 정규화 좌표, 선택선 방향도 제공합니다.
   CSS는 0도 위, 90도 오른쪽, 시계방향입니다.
   디자인 도구마다 각도 기준과 중간색 혼합 방식이 다를 수 있습니다.

4. 2색·3색 대안을 선택하면 색상표·입력 PNG·예상 PNG·통계·PNG 저장·
   큰 비교창이 같은 선택을 사용합니다. 첫 실행에는 더 좋은 3색이 있으면
   3색을 권장하며, 사용자가 바꾼 선택을 이후 실행에도 존중합니다.

5. 단색·그라데이션 결과별로 기준색 근처·전환·외삽을 구분합니다.
   비율은 유채색 표본을 분모로 하며 중성·저채도는 별도로 셉니다.
   유채색 표본이 없으면 비율을 계산하지 않습니다. 보정 반경을 바꾸면
   분류도 그 반경을 사용합니다. 근접도는 정확도나 성공확률이 아닙니다.

6. 강한 잉크량 제한에서 유효한 그라데이션 후보를 놓치는 탐색을 개선했습니다.
   기존 후보도 유지하고, 모든 후보를 전체 양자화 경로의 TAC 검증 뒤
   같은 목적함수로 비교합니다. API 100% TAC 재현 사례의 2색 평균
   ΔE76은 33.715에서15.639로 개선됐습니다. 잔여 오차가 있으므로
   정확히 재현됐다는 뜻은 아닙니다. 일반 화면의 최저 선택은240%입니다.

7. 제조사 등 헤더만 다른 동등 FOGRA PDF OutputIntent는 표준 경로의
   DeviceCMYK 기본 프로파일을 정규화합니다. 원본 PDF, 사진 경로,
   서로 다른 명시적 ICC 객체는 유지합니다. 명시적 ICCBased 객체의
   동등 프로파일까지 강제로 바꾸지 않으며 해당 경계는 경고합니다.

유지한 기준
  사진 모델 수식, 기본13영역, 고유 입력10색, GRACoL/FOGRA ICC는 그대로입니다.
  사진 경로와 표준 프루프는 분리하며 중복 보정을 허용하지 않습니다.
  새 색의 전역 외삽은 계속 동작하지만 새 실물의 정확도 검증은 아닙니다.
  기존 학습 평균 ΔE76 1.58과 동일 입력 묶음 제외 평균5.81/최대19.91은
  같은 사진 자료에 대한 지표입니다. 모니터·Windows 색 설정은 변경하지 않습니다.

검증
  색상 UI 실제 함수의 응답 순서 역전·조건 재확인, 실제 HTTP API,
  그라데이션 UI와 전 구간 TAC, PDF ICC 회귀를 실행했습니다.
  자세한 새 결과는 verification_results/update_v11_2에 보관했습니다.
  Windows 번들 검증 스크립트는 verification_sources/verify_release_v11_2.py입니다.
  GitHub 릴리스는 이 스크립트를 원격 Windows에서 실제 번들 Python·GS9.50으로
  통과한 뒤 게시하도록 구성했습니다. 실제 사용자 PC 설치·화면·실물 인쇄 확인은
  원격 검증과 구분합니다. 브라우저 시각 검사는 실행 환경 제한으로 완료하지 못했습니다.

설치

  기존V11/V11.1: 종료→폴더전체백업→Update.zip의 UPDATE_FILES 내용 덮어쓰기→START.cmd.
  사용자 state/calibration.json, 업로드·내보내기 자료는 패치에 포함하지 않습니다.

이력
