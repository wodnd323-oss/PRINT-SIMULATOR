## HARDYS 인쇄색 시뮬레이터 V11.2

2026-11-23 목적 적합성 재검토에서 확인한 조회·재확인·그라데이션·PDF 경계를 보완했습니다. 사진 모델 수식과 기준 보정값, GRACoL/FOGRA 프로파일은 유지합니다.

### 설치

- 신규: `HARDYS_PrintSimulator_v11_2_Full_Install.zip`을 전부 풀고 `START.cmd`를 실행합니다.
- 기존 V11/V11.1: 프로그램을 종료하고 설치 폴더 전체를 백업한 뒤, `HARDYS_PrintSimulator_v11_2_Update.zip`의 `UPDATE_FILES` 내용만 기존 설치 폴더에 덮어씁니다.
- 사용자 보정 상태·업로드·내보내기 자료와 Windows/모니터 색 설정은 변경하지 않습니다.

### 주요 변경

- 이전 색상 조회의 늦은 성공·실패 응답이 최신 결과를 덮어쓰지 않습니다.
- 직접 색상 비교에서 사진/ICC 모드를 선택하고, 추천 RGB·CMYK를 같은 모드·프로파일·사진 강도·보정 기준으로 재확인합니다.
- 그라데이션 CSS 각도·좌표 기준을 명시하고 2색/3색 선택을 표·통계·PNG 저장·큰 비교에 함께 적용합니다.
- 결과별 사진 기준색 근처·전환·외삽을 표시하고 중성·저채도는 별도로 셉니다.
- 강한 잉크량 제한에서도 유효한 그라데이션 후보를 탐색하고 전체 양자화 경로의 TAC를 검증합니다.
- 동등 FOGRA OutputIntent의 헤더 차이로 생기던 DeviceCMYK 표준 경로 차이를 보완합니다. 명시적 ICC 객체는 유지하며 남은 ICCBased 경계는 경고합니다.

### 검증 자료

HTTP 69개, 색상 UI 함수 9개, 그라데이션 UI 함수 20개, 역산·지원범위 88개와 PDF ICC 7그룹을 점검했습니다. 릴리스는 별도 Windows 환경에서 실제 번들 Python·Ghostscript 9.50 검증이 통과해야 공개됩니다.

- `SHA256SUMS`: 전체본·패치의 SHA256.
- `BUILD_VERIFICATION.json`: 전체 파일 및 패치 대응 파일 검증.
- `WINDOWS_VERIFICATION.json`: Windows 번들 실행 결과. `all_pass`와 `release_gate_eligible` 모두 true여야 합니다.
- `PUBLIC_DOWNLOAD_VERIFICATION.json`: 게시한 ZIP 재다운로드 해시 검증 결과. 릴리스 생성 후 추가됩니다.

브라우저가 실행 환경에서 시작 전에 차단되어 실제 화면의 시각 검사는 완료하지 못했습니다. 사용자 PC에 자동 설치한 결과가 아니며, 모니터·인쇄소 RIP·실물의 색 정확도를 검증한 기록과 구분합니다. 학습 사진 평균 ΔE76 1.58, 같은 입력색 묶음 제외 평균 5.81·최대 19.91은 기존과 같고 새로운 색 계열은 외삽입니다.
